On a Mac, use <kbd>⌘</kbd> wherever this page says <kbd>Ctrl</kbd>.

## Anywhere

| Keys | What they do |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>1</kbd> | Live tab |
| <kbd>Ctrl</kbd>+<kbd>2</kbd> | Timelapse tab |
| <kbd>Ctrl</kbd>+<kbd>3</kbd> | Load tab |
| <kbd>Ctrl</kbd>+<kbd>4</kbd> | Settings tab |
| <kbd>F11</kbd> | Full-screen window |
| <kbd>Esc</kbd> | Close a menu, leave full screen, or go back from a camera to the grid |

## The grid

| Keys | What they do |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Zoom the grid in / out (the mouse wheel zooms where the pointer is) |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Show the whole view again |
| <kbd>Esc</kbd> | Finish arranging |

## Live view and playback

These work on the Live tab when you're not typing in a field.

| Keys | What they do |
|---|---|
| <kbd>Space</kbd> or <kbd>K</kbd> | Pause and resume |
| <kbd>J</kbd> | One speed step slower. Past 1× it plays backwards; from live, starts reverse playback from now |
| <kbd>L</kbd> | One speed step faster |
| <kbd>←</kbd> / <kbd>→</kbd> | Back / forward 10 seconds |
| <kbd>[</kbd> / <kbd>]</kbd> | Previous / next alert or detection |
| <kbd>+</kbd> / <kbd>-</kbd> | Zoom the timeline in / out |
| <kbd>Shift</kbd> + drag on the timeline | Select a range |
| <kbd>Esc</kbd> | Clear the selection; or, when playing back the grid, return to live |

## Moving a PTZ camera

When a [PTZ camera](camera-view.md#moving-a-ptz-camera) is open and live:

| Keys | What they do |
|---|---|
| <kbd>Shift</kbd>+<kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Pan and tilt while held |
| <kbd>Shift</kbd>+<kbd>=</kbd> / <kbd>Shift</kbd>+<kbd>-</kbd> | Zoom in / out while held |
| Double-click the picture | Point the camera at that spot (if the camera supports it) |

## Mouse and trackpad on the timeline

| Action | What it does |
|---|---|
| Scroll or pinch | Zoom around the pointer |
| Drag | Move through time |
| Click | Play from that moment |
| Hover a marker | Show the event's thumbnail |
| Double-click the speed slider | Back to 1× |

## Config editor

| Keys | What they do |
|---|---|
| <kbd>Tab</kbd> | Indent with two spaces |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
