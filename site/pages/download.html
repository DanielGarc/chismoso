Download Chismoso

Free and open source. Installs in seconds, takes about 10 MB, and connects to the Frigate server you already have.

Download from GitHub

Not sure which Mac you have? Open the Apple menu → About This Mac. If it lists a Chip (M1, M2, …) it's Apple Silicon; a Processor (Intel Core …) means Intel.

After you download

macOS says it can't be opened

The Mac builds aren't notarized yet. Right-click the app in Finder, choose Open, and confirm. You only do this once. Details

Windows shows SmartScreen

The installer isn't code-signed yet, so Windows doesn't recognize it. Choose More info → Run anyway. Details

Linux video playback

The .deb and .rpm pull in the GStreamer plugins video needs. For the AppImage, or for hardware decoding, see Linux notes.

Then sign in

Enter your Frigate address and account. Recordings playback needs Frigate 0.17 or newer. Connecting to Frigate

Build it yourself

Prefer to compile it? You need Rust and a few system libraries. See Building from source, or browse every past version on the releases page.
